# RGB2link developer skills

These are agent skill instructions, not product plugins. Invoke/read only the relevant skill for the task; do not treat a skill file as evidence that corresponding software is implemented.

| Skill | Trigger | Result |
|---|---|---|
| `rgb2link-core` | n2link node registration, compiler or editor | Validated deterministic visual flow |
| `rgb2link-wallet` | RGB wallet or network integration | Isolated capability-tested wallet gateway |
| `rgb2link-qvac` | Local AI intent and template drafting | Strict typed untrusted intent output |
| `rgb2link-capsules` | Service supervision, regtest, Redis | Safely provisioned approved process/container |
| `rgb2link-security` | Approval, signing, secrets, threat checks | Fail-closed security review |
| `rgb2link-tests` | Acceptance/release checks | Reproducible functional and failure tests |

Read the relevant `.agents/skills/<name>/SKILL.md` and referenced design/acceptance docs before implementing.
